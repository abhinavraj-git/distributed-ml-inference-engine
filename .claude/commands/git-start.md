---
description: Start a feature branch from an up-to-date main
argument-hint: <id>
allowed-tools: Bash(git pull:*), Bash(git checkout:*), Bash(git switch:*)
---

Run these commands in order:

1. `git pull origin main`
2. `git checkout -b feature/$0`
3. `git switch feature/$0`

Change no file. Do not explain. Do not ask questions. Do only these steps, then stop.
