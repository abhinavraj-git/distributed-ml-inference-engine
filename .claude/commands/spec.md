1. Read `CLAUDE.md`, `SCOPE.md` and `PROGRESS.md`.
2. `$0` is the feature id. The rest of `$ARGUMENTS` after the id is the requirements.
3. Write `specs/$0/spec.md` with these sections, using only those requirements:
   - Goal
   - Scope
   - Out of scope
   - Files
   - Acceptance criteria
4. Write no code.

Do not explain. Do not ask questions. Do only these steps, then stop.
